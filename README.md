# X AIアシスタント

WordPress記事の投稿文作成、予約、Xへの自動投稿、メンション通知、人間確認型の交流支援を行う専用プラグインです。AI APIは使用しません。

## バージョン3.0.1

V3.0.1では、交流操作の重複実行防止、保存データの自動削除、アンインストール時の削除設定、配布経路の固定を追加しました。

標準の投稿文は次の形式です。

```text
ブログ更新しました。
ご興味ある方は、読んでみてください。

{title}

{url}

{hashtags}
```

### 記事編集画面

- 記事単位でX投稿をON／OFF
- 記事専用の投稿文を設定
- 実際に送信される文章をプレビュー
- Xへの投稿日時を予約
- X投稿済みIDを表示

### WordPress内での投稿文生成

- `{title}`：記事タイトル
- `{excerpt}`：記事の抜粋。未入力なら本文から生成
- `{url}`：記事URL
- `{hashtags}`：記事タグとカテゴリーから最大5件
- `{categories}`：カテゴリー名

AIによる文章生成、外部検索、外部ハッシュタグAPIは使用しません。

### X連携

- 下書き・予約投稿から初めて公開されたタイミングを検知
- OAuth 1.0aでX API v2の`POST /2/tweets`へ投稿
- 投稿成功・エラー・予約登録のログを保存
- 二重投稿と同時実行を防止
- SodiumまたはOpenSSLで認証情報を暗号化保存
- 確認画面付きの実投稿テスト

### X交流支援

- 記事をXへ投稿した後、週1回まで関連候補を取得
- 記事タグ・カテゴリーを使って最大5件の候補を表示
- メンションを1時間ごとに確認し、前回以降の新着だけを保存
- 新着メンションがある場合だけ、複数件を1通にまとめてメール通知
- ChatGPTへ渡す返信作成用プロンプトをコピー
- 人間が確認した返信文だけをXへ送信
- いいね・フォローは候補表示後に人間がボタンを押した場合だけ実行
- 同じ候補・メンションの重複取得と重複操作を防止
- 管理画面とCronが同時に動いても、原子的ロックで二重返信・状態上書きを防止

完全自動の返信、いいね、フォローは行いません。返信文の作成には契約中のChatGPTを手動で利用し、OpenAI APIなどの有料AI APIは使いません。
XのセルフサービスAPI仕様に合わせ、プラグインからの返信対象は自分へのメンションとして取得した投稿に限定します。

### 月980円以内を目指す共通予算

- 記事投稿、候補取得、メンション、返信、いいね、フォローを合算
- プラグイン内の上限は月4.50米ドル相当
- 記事投稿4.00、候補取得0.25、メンション0.10、返信・いいね・フォロー0.13、本人確認0.02米ドル相当に配分
- 上限を超える可能性がある場合はX APIへ通信する前に停止
- 管理画面に今月の使用額相当と残額相当を表示
- サイトのタイムゾーンを基準に、月が変わると自動で利用枠を更新

費用はXの公開単価を使った安全側の内部計算です。X側の料金変更、為替、税金、ほかのアプリによるAPI利用はプラグインから取得しないため、X Developer Consoleでも利用上限を5米ドルに設定し、自動チャージをOFFにしてください。

## インストール

リリースZIPをダウンロードし、WordPress管理画面の「プラグイン → プラグインを追加 → プラグインのアップロード」からインストールします。または、このフォルダを`wp-content/plugins/x-ai-assistant`へ配置してください。

有効化後、「設定 → X AIアシスタント」を開いて認証情報を入力します。X開発者アプリには読み取り・書き込み権限が必要で、アクセストークンは投稿先のXアカウントに対応している必要があります。

## 使い方

1. 「設定 → X AIアシスタント」で共通テンプレートとX API認証情報を保存します。
2. 記事編集画面の「X AIアシスタント」パネルを確認します。
3. 必要に応じて記事専用の投稿文や予約日時を指定します。
4. 記事を公開します。
5. 「設定 → X交流支援」でメンションと交流候補を確認します。

初回のメンション確認では過去分を一覧へ取り込みますが、過去分の通知メールは送りません。2回目以降は新着がある場合だけ通知します。

予約にはWordPress Cronを使用します。予約時刻を過ぎた後、サイトへのアクセスを契機として処理されるため、アクセスが少ないサイトでは多少遅れる場合があります。
メンション確認もWordPress Cronを使用するため、アクセスが少ないサイトでは1時間より遅れる場合があります。
メール通知にはWordPress標準の`wp_mail()`を使用します。サーバーのメール送信設定によっては、SMTPプラグインなどの設定が必要です。

メンション、交流候補、投稿ログの保持期間は設定画面で30〜365日の範囲から指定できます。初期値は90日です。設定画面から交流データとログを即時消去することもできます。

## Git Updater

メインのプラグインファイルには、Git Updaterが読み取る次の必須ヘッダーを設定しています。

```text
GitHub Plugin URI: https://github.com/healingyasu/x-ai-assistant
Primary Branch: main
Release Asset: true
```

タグをGitHubへ送信すると、GitHub Actionsが`x-ai-assistant.zip`を生成してリリースへ添付します。
配布に使うGitHub Actionsは、可変タグではなく検証済みのコミットSHAへ固定しています。

## セキュリティ

- 認証情報をリポジトリへ保存しません。
- パスワード入力欄へ保存済みの値を再表示しません。
- 設定変更とテスト投稿には、権限確認とWordPressのnonce検証が必要です。
- 入力値を無害化し、画面出力をエスケープします。
- Xへの通信にはWordPressの安全なHTTP APIを使い、リダイレクトを許可しません。
- WordPressの`AUTH_KEY`から生成した鍵で認証情報を暗号化します。
- 認証情報を含む設定はWordPressの自動読込対象外として保存します。
- メンション、候補、返信、いいね、フォロー、テスト投稿の同時実行をサーバー側で防ぎます。
- 保存データは初期設定で90日後に自動削除し、管理画面から即時消去できます。

WordPressのソルトを変更した場合は、認証情報を再入力してください。SodiumとOpenSSLのどちらも利用できない環境では、認証情報を保存しません。

## 今回の対象外

有料AI APIによる返信文の自動生成、無人での返信、完全自動のいいね・フォロー、DMの自動処理は含みません。
