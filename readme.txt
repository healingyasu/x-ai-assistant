外部AI APIを使わず、WordPress記事のX投稿と人間確認型の交流支援を行います。

== 説明 ==

X AIアシスタントは、WordPress内で投稿文とハッシュタグを作成し、OAuth 1.0aのユーザー認証を使ってX APIへ投稿します。

主な機能：

* 記事単位でX投稿をON／OFFできます。
* 記事専用の投稿文、プレビュー、X投稿予約日時を設定できます。
* タイトル、抜粋、URL、タグ、カテゴリーを投稿文へ反映できます。
* タグとカテゴリーから最大5件のハッシュタグを作成します。
* 二重投稿と同時実行を防ぎます。
* 成功・エラー・予約登録のログを保存します。
* SodiumまたはOpenSSLでAPI認証情報を暗号化します。
* Git UpdaterとGitHubリリースによる更新に対応します。
* 記事投稿と交流機能を合計4.50米ドル相当までに制限します。
* 管理画面に今月の使用額相当と残額相当を表示します。
* 記事投稿後、週1回まで関連する交流候補を最大5件取得します。
* メンションを1時間ごとに確認し、新着がある場合だけメール通知します。
* ChatGPT用プロンプトのコピーと、確認後の返信送信に対応します。
* いいね・フォローは人間が候補を確認して実行します。
* 交流操作の原子的ロック、90日を初期値とするデータ保持期間、即時消去に対応します。

X API以外の外部APIは使用しません。
標準テンプレートは「ブログ更新しました。ご興味ある方は、読んでみてください。」に、記事タイトル、URL、ハッシュタグを続ける形式です。
記事投稿と交流機能を合計4.50米ドル相当までに制限し、上限到達後はX APIへ通信する前に停止します。X Developer Console側でも利用上限5米ドル・自動チャージOFFを推奨します。
内訳は記事投稿4.00、候補取得0.25、メンション0.10、返信・いいね・フォロー0.13、本人確認0.02米ドル相当です。

== インストール ==

1. リリースZIPをインストールするか、リポジトリを`wp-content/plugins/x-ai-assistant`へ配置します。
2. プラグインを有効化します。
3. 「設定 → X AIアシスタント」を開きます。
4. X APIの認証情報と共通テンプレートを保存します。
5. 記事編集画面の「X AIアシスタント」パネルで投稿内容を確認します。
6. 「設定 → X交流支援」でメンションと交流候補を確認します。

X APIのアカウントとクレジットでは、`POST /2/tweets`が許可されている必要があります。テスト投稿を実行すると、Xへ実際に公開されます。
交流支援では読み取り・書き込み権限を使います。返信対象は自分へのメンションとして取得した投稿に限定します。メール通知にはWordPress標準の`wp_mail()`を使用します。
